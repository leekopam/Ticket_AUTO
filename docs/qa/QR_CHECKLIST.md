# QR 자동화 체크리스트

QR 스캔 → 수령처리 → 영수증 출력 전체 흐름의 수동 QA 및 회귀 검증 체크리스트.  
새 기능 추가 또는 관련 코드 수정 후 반드시 확인한다.

## 6. httpx 오프라인 QR 해석 (`_resolve_qr_offline`)

| # | 확인 항목 | 예상 결과 |
|---|-----------|-----------|
| 6-1 | 오프라인 모드 + 실제 witchform QR (로그인 필요) | httpx가 최종 URL(`/w/login?redirect=...`)까지 따라가 주문번호 추출 시도 |
| 6-2 | 서버가 200으로 로그인 페이지 반환 시 | status_code=302, location=final_url 로 변환해 AUTH_REQUIRED 처리 경로 진입 |
| 6-3 | `?test_order=ORDER_ID` 파라미터 포함 QR | httpx 호출 없이 즉시 fake 302 반환 |

> **과거 버그**: `follow_redirects=False` 사용으로 서버의 최종 200 응답을 받아 `REDIRECT_MISSING` 에러 발생  
> **수정**: `follow_redirects=True` + `str(resp.url)` 로 최종 URL 확인
