# Attempt Log — 시도 이력

이 문서는 에이전트 작업 중 시도한 방법, 성공/실패 여부, 근거, 사용자 피드백을 누적한다. 같은 실패를 반복하지 않기 위해 새 작업 시작 전에 관련 항목을 확인한다.

## 기록 규칙

- 의미 있는 구현 시도, 디버깅 시도, 검증 실패, 부분 성공, 롤백은 반드시 기록한다.
- 단순한 파일 저장이나 사소한 포맷 수정은 기록하지 않아도 된다.
- 사용자 피드백이 있으면 해당 시도 항목에 연결한다.

## 상태 값

- 성공
- 실패
- 부분 성공
- 보류
- 롤백
